# Helping Military Veterans Website

Open this folder in Visual Studio Code. Start by replacing every piece of visible text marked with `Replace` or surrounded by brackets.

## Files

- `index.html` - Home page with background image and feature images
- `questions.html` - Form page
- `resources.html` - List, table, and external links
- `policy.html` - Required purpose and accessibility statement page
- `styles.css` - External responsive stylesheet
- `script.js` - External JavaScript with a mobile menu, current year, and demo form behavior
- `images/` - Website image files
- `image-credits.md` - APA-style image credit list

## Checklist coverage

- Four HTML pages with shared navigation
- External CSS and JavaScript files
- Desktop and mobile responsive layout
- Form, table, list, and external hyperlinks
- Policy page with purpose and accessibility sections
- Metadata on every page
- Semantic headings, paragraphs, `header`, `nav`, `main`, `section`, `article`, and `footer` elements
- Background image plus four image elements
- Comments in HTML, CSS, and JavaScript

## Before submitting

1. Replace the placeholder wording.
2. Add the original source URLs and APA citations for the new photos to `image-credits.md`.
4. Update the website title, descriptions, keywords, and footer text.
5. Test every navigation link and test the form in a browser.
